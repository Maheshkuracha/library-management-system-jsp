# Library Management System (JSP + JDBC)

## Description
This is a web-based Library Management System developed using JSP, JDBC, and MySQL. It allows users to register, login, borrow books, return books, and view borrowed books.

## Features
- User Registration
- User Login and Logout
- View Available Books
- Borrow Books
- Return Books
- View My Borrowed Books
- Session Management

## Technologies Used
- Java
- JSP
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat

## Database
Database Name: libraryjsp

Tables:
- users
- books
- borrow

## How to Run
1. Import project into Eclipse
2. Configure Tomcat Server
3. Create MySQL database
4. Run project on server
